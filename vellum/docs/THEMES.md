# The theme catalogue

**250 themes — 31 free, 219 Pro.** Free themes are marked `*`.

The number in front of each name is its catalogue number, shown in the popup grid.
Numbers run 001–250 with no gaps; `scripts/verify.js` enforces that.

Sections shown in the popup sidebar, in order: Favourites, New, All, Free (hidden
once you are entitled), Space, City, Cyber, Seasonal, Nature, Weather, Fire,
Retro, Minimal, Abstract, Ambient, Geometric, Audio. "Favourites" and "New" are
derived, not stored on the theme: favourites come from sync storage, "New" is the
`isNew` flag in `popup/popup.js`.

## The two synthetic themes

These are not in the catalogue and never appear in the grid:

- `__company` — a branded background from a company code. Resolved from
  `companyConfig` in sync storage at apply time.
- `__custom` — the user's own uploaded image. Resolved from `customBg` in local
  storage. Gated on the same entitlement as any Pro theme.
